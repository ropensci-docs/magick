# Magick Image Processing

The `magick` package for graphics and image processing in R. Important
resources:

- [R introduction
  vignette](https://docs.ropensci.org/magick/articles/intro.html):
  getting started

- [Magick++ API](https://imagemagick.org/Magick++/Image++.html) and
  [Magick++ STL](https://imagemagick.org/Magick++/STL.html) detailed
  descriptions of methods and parameters

## Details

Documentation is split into the following pages:

- [analysis](https://docs.ropensci.org/magick/reference/analysis.md) -
  metrics and calculations: `compare`, `fft`

- [animation](https://docs.ropensci.org/magick/reference/animation.md) -
  manipulate or combine multiple frames: `animate`, `morph`, `mosaic`,
  `montage`, `average`, `append`, `apply`

- [attributes](https://docs.ropensci.org/magick/reference/attributes.md) -
  image properties: `comment`, `info`

- [color](https://docs.ropensci.org/magick/reference/color.md) -
  contrast, brightness, colors: `modulate`, `quantize`, `map`,
  `transparent`, `background`, `colorize`, `contrast`, `normalize`,
  `enhance`, `equalize`, `median`

- [composite](https://docs.ropensci.org/magick/reference/composite.md) -
  advanced joining: `composite`, `border`, `frame`

- [device](https://docs.ropensci.org/magick/reference/device.md) -
  creating graphics and drawing on images

- [editing](https://docs.ropensci.org/magick/reference/editing.md) -
  basic image IO: `read`, `write`, `convert`, `join`, `display`, `brose`

- [effects](https://docs.ropensci.org/magick/reference/effects.md) - fun
  effects: `despecle`, `reducenoise`, `noise`, `blur`, `charcoal`,
  `edge`, `oilpaint`, `emboss`, `implode`, `negate`

- [geometry](https://docs.ropensci.org/magick/reference/geometry.md) -
  specify points, areas and sizes using geometry syntax

- [ocr](https://docs.ropensci.org/magick/reference/ocr.md) - extract
  text from image using
  [tesseract](https://docs.ropensci.org/tesseract/reference/tesseract.html)
  package

- [options](https://docs.ropensci.org/magick/reference/options.md) -
  list option types and values supported in your version of ImageMagick

- [painting](https://docs.ropensci.org/magick/reference/painting.md) -
  flood fill and annotating text

- [transform](https://docs.ropensci.org/magick/reference/transform.md) -
  shape operations: `trim`, `chop`, `rotate`, `resize`, `scale`,
  `sample` `crop`, `flip`, `flop`, `deskew`, `page`
